# Contributing

Thanks for stopping by the lounge. maître is early, so the most useful contributions right now are bug reports on the demo lounge and ideas for the roadmap. Open an issue before starting anything large, so we can agree on the shape first.

## Setup

```sh
git clone https://github.com/danielrdg/maitre
cd maitre
npm install
npm test        # builds the TypeScript, then runs every test
npm run demo    # opens the lounge with simulated agents
```

Requirements: Node.js 20 or newer, on Linux.

## Ground rules

- **Everything in English:** code, comments, commit messages, docs and CLI output. The lounge's interface strings live in `lounge/js/i18n.js`; any new string needs both `en` and `pt-BR`.
- **Tests first.** Add or change a test, watch it fail, then make it pass. TypeScript tests live in `test/*.test.ts`; lounge tests are plain ES modules in `test/lounge/*.test.mjs`, run with `node --test`.
- **No third-party assets.** Sprites, scenery, sound effects and music are generated by code. Fonts must be under the SIL Open Font License.
- **No network in the lounge.** It loads nothing from a CDN, and the server binds to `127.0.0.1` with a token.
- **Agent text is text.** Anything that comes from an agent is rendered with `textContent`, never as HTML.
- **Nothing personal in the repo.** No real project names, PR titles, paths or configs in code, demo data or screenshots. Personal state belongs in the gitignored `state/`, `memory/` and `config/*.local.*`.
- **Small pull requests** on a feature branch, with [Conventional Commits](https://www.conventionalcommits.org/) messages (`feat(lounge): …`, `fix(cli): …`, `docs: …`).

## README art

The banner, the demo GIF, the state sheet, the feature sprites, the favicon and the app icons are rendered from the lounge's own code. After a change to how the lounge looks, regenerate them and commit the result:

```sh
npm run assets  # needs Chrome or Chromium (or CHROME_PATH) and ffmpeg
```

The GIF is recorded from `?demo=1&capture=1&seed=42` on a simulated clock, so with the same Chrome and ffmpeg an unchanged lounge renders byte-identical files.

## Design

The design and its open questions are in [docs/design.md](docs/design.md). If a change moves away from it, update the design in the same pull request.
